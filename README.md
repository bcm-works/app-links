# Links Service

This directory contains a self-hosted version of the [Karakeep](https://karakeep.app/) bookmarking service.

Requires the latest stable version of [Docker](https://www.docker.com/) to be installed and running.

## Local Environment

Start the local server:

```bash
bash ./start-links.sh
```

Stop the local server:

```bash
bash ./stop-links.sh
```
